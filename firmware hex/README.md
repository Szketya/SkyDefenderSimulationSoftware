# Panel Firmware

Only flash firmware when a SkyDefender release note or support instruction identifies an update for your exact panel. SkyDefender v1.0.0 does not require a firmware update.

| File | Panel | SHA-256 |
| --- | --- | --- |
| `ARC159+TACAN.hex` | ARC-159 and TACAN panel firmware | `69df8d41b097bb993e5e41c20837da5dbd06563a88af47d3d79a47caf97beff5` |
| `Mi24WP.hex` | Mi-24 Weapon panel | `f3e9686f4c1c3947cd4665b298235e5f087aa894be37c22ddd08de744bcc45b2` |

Do not disconnect the panel while flashing. Select the existing panel assignment again if Windows gives it a different COM number afterward.
